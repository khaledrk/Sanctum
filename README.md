# EREÍPIAPÓLIS — V7.2 fragment system

Five-page submission website:

- Home
- About
- Ruins Regrounded
- Partners + Clients
- References

V7.2 uses a fragment-based visual system: full-view drawings remain the dominant evidence; fragments work as secondary navigation; smooth panel transitions carry the homepage; every drawing uses contain-fit and opens independently for close inspection. Large typography is set entirely in IBM Plex Mono. Open-call variants remain editable in the interface.
