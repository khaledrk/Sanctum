# EREÍPIAPÓLIS — final ENVT 1126 website

This version continues from the asset-rich `EREIPIApolis-V7.2-restored-download.zip` build. It does not use the lightweight diagram-only branch as its content base.

## Assessed five-page structure

- `index.html` — Home: A0 field and fragment entry
- `about.html` — About: position, origin, method and manifesto
- `project.html` — Project: edited Ruins Regrounded narrative and full PDF
- `partners.html` — Partners + Clients: prospective site and practice network
- `references.html` — References: evidence, theory, precedents and influences

## Editorial decisions

- The Project page uses ten updated panels in the sequence: history → recording → cartography → dispositions → proposal → occupation.
- The full ENVT 1126 PDF remains available for completeness; the web page is deliberately edited rather than exhaustive.
- Organisations on the Partners + Clients page are labelled as a prospective network unless already evidenced as a site owner or authority.
- References are separated by evidentiary role so theory, live site material and fictional influences are not presented as equivalent.
- The atmosphere, cursor, fog, particles, sound option, A0 entry and five-page public structure of the v7.2 build are preserved.

Open `index.html` directly or serve the folder with any static web server.
