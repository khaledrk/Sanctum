# Iribiopolis — show-ready build

Open `index.html` for a local preview, or deploy this entire folder to Netlify.

## Public structure
- `index.html` — homepage
- `projects.html` — practice projects
- `research.html` — research archive
- `making.html` — physical and digital making
- `exhibitions.html` — talks, exhibitions, workshops and public programmes
- `project.html?id=...` — individual project pages

## Quick live preview
1. Go to Netlify Drop.
2. Drag this whole folder onto the page.
3. Netlify returns a public HTTPS link.

## Content editing
Use `admin.html` locally. It is marked `noindex`, but it is not a secure online backend. For a private production editor, connect Sanity or Decap CMS before publishing an admin route.
