04 / REFERENCES

An intellectual ecology.

These references do different kinds of work. Site records establish what is there. Theory sharpens the practice’s position. Built precedents test methods. Fictional worlds extend atmosphere and temporal imagination without being treated as evidence.

Editorial rule

Evidence, theory, precedent and atmosphere are kept visible as different categories. Every reference must explain a decision, sharpen a method or locate the work; none is included only because it shares a ruin aesthetic.
